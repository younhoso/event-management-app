# 08. Guidelines — 하지 말 것 (가장 중요한 파일)

앞의 7개 파일이 "무엇을 쓸지"를 정한다면, 이 파일은 "어디에 쓸지 / 어디까지만 쓸지"를 정한다.
값만 정하고 이 파일이 비어 있으면 시스템은 절반만 작동한다.

## 채우는 칸

```
## Guidelines

### DO
- 포인트 색은 [                              ] 에만 쓴다
- 화면마다 주 버튼은 하나. 나머지는 보조 버튼이나 글자 링크
- 카드는 [06번에서 고른 방식] 으로만 구분한다. 다른 방식을 섞지 않는다
- [                              ]

### DON'T
- [                              ]
- [                              ]
- [                              ]
```

## 작성 규칙

- **일반론을 적지 말고, 직접 겪은 것을 적는다.** 화면을 한 번 뽑아보고 마음에 안 든 부분을 그대로 옮긴다
  - 예: "글자에 그림자가 껴서 싫었다" → "글자에 그림자 금지"라고 적는다
- **금지형이 더 잘 지켜진다.** "이 값만 쓴다"보다 "이 값 아니면 쓰지 않는다"가 훨씬 강하게 작동함
- 완벽하게 채우려 하지 않는다. 3줄로 시작 → 걸리는 게 생길 때마다 한 줄씩 추가하는 방식이 실제로 더 잘 작동함
- 이 파일은 프로젝트가 진행되며 계속 자라는 파일 — 한 번 쓰고 끝나는 문서가 아님

## 어떤 아이덴티티에도 해당하는 기본값 (그대로 깔고 시작해도 됨)

값이 아니라 **규칙**이라 어떤 디자인 방향에도 그대로 적용됨. 겪는 대로 아래에 한 줄씩 추가한다.

```
### DO
- 포인트 색은 주 버튼과 선택된 상태에만 쓴다
- 화면마다 주 버튼은 하나. 나머지는 보조 버튼이나 글자 링크
- 카드는 06번에서 고른 한 가지 방식으로만 구분한다
- 가까운 것은 붙이고 먼 것은 띄운다 (04번 묶임 규칙)
- 색은 토큰/변수 이름으로 참조한다 (값을 컴포넌트에 직접 박지 않는다)

### DON'T
- 02번 색상표에 없는 색을 추가하지 않는다
- 03번에 정한 굵기 외의 굵기를 쓰지 않는다
- 04번 스케일에 없는 중간값을 쓰지 않는다
- 05번에 없는 모서리 값을 쓰지 않는다 (특히 원형은 999 고정, 절반 계산 금지)
- 06번에서 안 쓰기로 한 깊이 표현을 임의로 추가하지 않는다
- 07번에 없는 컴포넌트 변형을 즉석에서 만들지 않는다
- 그라데이션, 글로우, 과한 그림자를 쓰지 않는다
- 글자에 그림자를 넣지 않는다
```

## 증상별 원인 체크표 (문제가 생겼을 때 참고)

| 증상 | 원인 | 해결 |
|---|---|---|
| 색은 맞는데 화면 느낌이 계속 바뀜 | DO/DON'T가 비어 있음 | 이 파일에 3줄부터 채우기 |
| 카드가 화면마다 떴다 가라앉았다 함 | 바탕/표면 밝기 관계 미지정 | 02번 마지막 줄 채우기 |
| 정해둔 것 외 모서리 값이 나옴 | 원을 크기의 절반으로 계산함 | "원형은 999" 명시 (05번) |
| 글자 굵기가 제멋대로 튐 | 크기만 적고 굵기를 안 적음 | 03번에 굵기 함께 명시 |
| 본문이 답답하게 붙어 보임 | 행간을 안 적어 기본값이 적용됨 | 03번에 행간 명시 |
| 두 번째 화면부터 규칙이 무너짐 | 첫 화면에만 파일을 전달함 | 화면 생성마다 매번 함께 전달 |
| 포인트 색이 여러 군데(배지/아이콘/구분선)에 쓰임 | "~에만 쓴다"는 제한 문장이 없음 | DO 첫 줄에 사용처 한정 명시 |
| 다크로 바꾸니 그림자가 사라져 평평해짐 | 깊이를 그림자에만 의존함 | 06번에서 테두리/배경색으로 변경 |
| 버튼과 입력창 높이가 안 맞음 | 07번에서 높이를 따로 지정함 | 하나의 높이 값으로 통일 |
| 상태(hover/disabled)마다 새 회색이 생김 | 상태 규칙 미지정 | "기존 색의 불투명도만 조정" 한 줄 추가 |

## 체크리스트
- [ ] "~하지 않는다" 형태의 금지 문장이 최소 3개 이상 있는가
- [ ] 실제로 겪은 문제를 반영했는가 (일반론이 아닌가)
- [ ] 포인트 색의 사용처를 명시적으로 제한했는가
- [ ] 색이 값 직접 입력이 아니라 토큰/변수로 참조되는가
