# 07. Components — 컴포넌트

색/크기/간격을 "어디에 쓸지" 실제 UI 요소에 연결하는 파일. 이 파일이 없으면 값은 지켜도 화면은 이상해짐
(예: 포인트 색을 정해줬는데 버튼이 아니라 제목 글자에 쓰는 경우).

## 채우는 칸

```
## Components
- 주 버튼 — [배경] + [글자색], 모서리 [05번 값], 높이 [__]px, 화면당 하나만
- 보조 버튼 — [배경] + [글자색] + [테두리 유무], 주 버튼과 같은 크기
- 카드 — [배경], 모서리 [05번 값], 안쪽 여백 [04번 값], [테두리/그림자 여부는 06번 값]
- 입력창 — [배경], 모서리 [05번 값], 높이 [주 버튼과 동일], 포커스 시 [            ]
- 칩(필터) — 기본 [배경] + [글자색], 선택되면 [배경] + [글자색]
```

## 작성 규칙

- **앞 파일에서 정한 값만 가져와 채운다. 여기서 새 값을 만들지 않는다.** 이 파일에 처음 보는 색이나 크기가 등장하면 시스템이 깨진 것
- **"화면당 하나만" 같은 사용 조건도 함께 적는다.** 주 버튼이 한 화면에 3개면 뭘 눌러야 할지 모르는 화면이 됨
- **칸을 비워두지 말고 "없음"이라고 적는다.** 테두리를 안 쓸 거면 "테두리 없음"이라고 써야 AI가 기본값을 넣지 않음

## 값을 정하는 기준

| 컴포넌트 | 어떤 값을 넣나 |
|---|---|
| 주 버튼 | 배경은 **포인트 색**, 글자는 그 위에서 4.5:1이 나오는 색. 화면에서 포인트 색이 칠해지는 거의 유일한 자리 |
| 보조 버튼 | **포인트 색을 쓰지 않는다.** 주 버튼과 같은 높이·모서리를 유지하고 배경/테두리로만 구분 |
| 카드 | 배경은 **표면 색**. 구분 방식(테두리냐 배경색 차이냐 그림자냐)은 06번에서 정한 하나만 |
| 입력창 | **주 버튼과 같은 높이.** 나란히 놓였을 때 높이가 다르면 정렬이 깨져 보임 |
| 칩 | 선택 전에는 무채색, 선택되면 **포인트 옅은 색 배경 + 포인트 색 글자** |

- **버튼과 입력창의 높이를 하나로 통일한다.** 이 값 하나가 폼 화면 전체의 인상을 결정
- **상태(hover/focus/disabled)를 새 색으로 만들지 않는다.** 이미 정한 색의 불투명도나 명도만 조정
- **비활성(disabled)은 글자 보조 색 + 배경 유지**로 처리. 별도 회색을 추가하면 8번째 색이 생김

## 프로젝트가 커지면 추가할 수 있는 컴포넌트 (선택)

```
- 배지/태그 — [배경] + [글자색], 상태별 색 구분 시 최대 3색(성공/경고/오류)까지만
- 위험 버튼 — 삭제 등 되돌릴 수 없는 동작에만. 확인 단계와 함께 쓸 것
- 탭 — 선택됨 [            ] / 선택 안 됨 [            ]
- 토글 — On [            ] / Off [            ]
- 빈 상태(Empty state) — 아이콘 + 1줄 설명 + (선택) 액션 버튼 1개
- 하단 네비게이션 — 아이콘 [활성색] / [비활성색], 최대 5개 탭
```

- **상태 색(성공/경고/오류)은 7개 색 밖의 예외.** 추가할 거면 "이 세 가지 외에는 만들지 않는다"까지 함께 적는다

## 버튼 종류를 정할 때 (필요한 만큼만)

| 종류 | 용도 | 화면당 개수 |
|---|---|---|
| 주 버튼 | 가장 중요한 행동 1개 | 1개 |
| 보조 버튼 | 그 외 행동 | 제한 없음 |
| 텍스트/링크형 | 비중 낮은 행동 | 제한 없음 |
| 아이콘 버튼 | 툴바, 반복되는 행동 | 제한 없음 |
| 위험 버튼 | 삭제 등 되돌릴 수 없는 행동 | 확인 단계와 함께 |

- **여기 적은 종류 외의 버튼 스타일을 즉석에서 만들지 않는다.** 종류가 늘어나는 순간 위계가 사라짐

## 체크리스트
- [ ] 다섯 개 기본 컴포넌트(주 버튼/보조 버튼/카드/입력창/칩)를 모두 채웠는가
- [ ] "화면당 하나만" 같은 사용 조건을 명시했는가
- [ ] 여기서 새로운 색이나 크기를 만들지 않았는가 (02~06번 값만 재사용)
- [ ] 안 쓰는 속성을 "없음"이라고 적었는가 (빈칸으로 두지 않았는가)
- [ ] 버튼과 입력창의 높이가 같은가
