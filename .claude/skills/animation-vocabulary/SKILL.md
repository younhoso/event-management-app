# 애니메이션 용어집

모션이나 효과에 대한 막연한 설명을 정확한 용어로 바꿔서, 사용자가 무엇을 요청해야 할지 알게 한다.

## 빠른 시작

사용자가 효과를 느슨하게 설명한다. 다음 형식으로 일치하는 용어(들)를 반환한다:

```
**Stagger** — 여러 항목을 작은 지연을 두고 하나씩 순서대로 애니메이션해서 캐스케이드 효과를 만든다.
```

여러 용어가 맞을 수 있다면, 가장 잘 맞는 것을 먼저 제시하고, 어떻게 다른지 한 줄로 설명하며 대안 1–2개를 덧붙인다.

## 지침

1. **키워드가 아니라 의도를 읽는다.** 사용자는 기술적 이름이 아니라 자신이 *보거나* *느끼는* 것("통통 튀는", "슬라이드로 사라지는", "스스로 그려지는")을 설명한다. 그 감각을 아래 용어집에 매핑한다.
2. **용어집을 그대로 인용한다.** 여기 설명은 권위 있는 원문이다 — 그대로 쓰고 바꿔 쓰지 않는다.
3. **비슷한 용어를 구별한다.** 두 개가 경쟁할 때(*Clip-path* vs *Mask*, *Pop in* vs *Bounce*, *Shared element transition* vs *Layout animation*), 사용자가 고를 수 있도록 대비시켜 설명한다.
4. **정확히 맞는 게 없을 때는** 가장 가까운 용어를 대며 근사치임을 솔직히 밝히거나, 용어집의 어휘로 효과를 설명한다(예: "그건 *scale-in* 진입의 *stagger*네요").
5. **이 용어집 안에 머문다.** 어떤 용어가 정말로 여기 없다면 지어내지 말고 그렇다고 말한다 — 다만 이 단어들을 이용해 개념을 설명할 수는 있다.
6. **간결하게 유지한다.** 이름을 묻는 질문에는 이름을, 에세이가 아니라. 용어를 먼저 제시하고, 요청받을 때만 확장한다.

## 예시

**예시 1 — 느낌 기반**
사용자: "팝오버가 자기 중앙이 아니라 클릭한 버튼에서 자라나는 것처럼 보이는 걸 뭐라고 해?"
출력:
```
**Origin-aware animation** — 요소가 CSS의 기본값인 자기 중앙이 아니라 트리거에서 밖으로 애니메이션된다. 팝오버가 그것을 연 버튼에서 자라나는 경우처럼.
```

**예시 2 — 구별**
사용자: "한 이미지가 다른 이미지로 변하는 그거."
출력:
```
**Morph** — 한 형태가 부드럽게 다른 형태로 바뀐다. 예: Dynamic Island.

비슷한 대안:
- **Crossfade** — 같은 자리에서 단순히 서로 겹치며 페이드된다면.
- **Shared element transition** — 요소가 한 위치에서 다른 위치로 이동하며 변형된다면.
```

**예시 3 — 물리적 느낌**
사용자: "너무 멀리 당기면 저항하다가 튕겨 돌아오는 iOS 스크롤 그거."
출력:
```
**Rubber-banding** — 경계를 넘어 드래그할 때의 저항과 스냅백(iOS 오버스크롤 느낌).
```

## 용어집

_프로젝트의 `/vocabulary` 페이지를 반영한 엄선된 스냅샷; 어느 쪽이든 바뀌면 둘을 동기화한다._

### 진입 & 퇴장 — 요소가 나타나고 사라지는 방식
- **Fade in / Fade out** — opacity를 바꿔서 요소가 나타나거나 사라진다.
- **Slide in** — 요소가 화면 밖(왼쪽, 오른쪽, 위, 아래)에서 슬라이드해 들어온다.
- **Scale in** — 요소가 나타나면서 작은 크기에서 원래 크기로 자란다. fade와 함께 쓰이는 경우가 많다.
- **Pop in** — 요소가 살짝 오버슈트하며 나타난다, 마치 튕기며 자리 잡는 것처럼.
- **Reveal** — 콘텐츠가 점진적으로 드러난다, 흔히 clip-path나 mask를 애니메이션해서.
- **Enter / Exit** — 요소가 화면에 추가되거나 제거될 때 재생하는 애니메이션.

### 시퀀싱 & 타이밍 — 여러 요소나 순간을 조율하기
- **Keyframes** — 애니메이션에서 정의된 지점(0%, 50%, 100%)이며 그 사이는 브라우저가 채운다.
- **Interpolation / Tween** — 시작값과 끝값 사이의 모든 중간 프레임을 생성해서 모션이 연속적으로 보이게 한다.
- **Stagger** — 여러 항목을 작은 지연을 두고 하나씩 순서대로 애니메이션해서 캐스케이드 효과를 만든다.
- **Orchestration** — 여러 애니메이션이 하나의 조율된 모션처럼 느껴지도록 의도적으로 타이밍을 맞춘다.
- **Delay** — 애니메이션이 시작되기 전의 시간.
- **Duration** — 애니메이션이 걸리는 시간.
- **Fill mode** — 요소가 애니메이션 시작 전이나 종료 후에 첫/마지막 프레임의 스타일을 유지할지 여부(예: forwards).
- **Stepped animation** — 카운트다운 타이머처럼 이산적인 단계로 나뉜 애니메이션.

### 움직임 & 변형 — 요소의 위치, 크기, 각도 바꾸기
- **Translate** — 요소를 X축 또는 Y축을 따라 이동시킨다.
- **Scale** — 요소를 크거나 작게 만든다.
- **Rotate** — 요소를 한 점을 중심으로 회전시킨다.
- **Skew** — 요소를 X축이나 Y축을 따라 기울여서 직사각형 형태를 비틀어낸다.
- **3D tilt / Flip** — 깊이감을 더하기 위해 3D 공간에서 회전시킨다(rotateX / rotateY).
- **Perspective** — 3D 효과가 얼마나 강해 보이는지 — 값이 낮을수록 깊이감이 과장되어, 보는 사람이 더 가까이 있는 것처럼 보인다.
- **Transform origin** — scale이나 rotation이 자라나거나 회전하는 기준점.
- **Origin-aware animation** — 요소가 CSS의 기본값인 자기 중앙이 아니라 트리거에서 밖으로 애니메이션된다. 팝오버가 그것을 연 버튼에서 자라나는 경우처럼.

### 상태 간 전환 — 한 상태, 뷰, 요소를 다른 것과 연결하기
- **Crossfade** — 한 요소가 같은 자리에서 페이드 아웃되는 동안 다른 요소가 페이드 인된다.
- **Continuity transition** — 전과 후를 시각적으로 연결해서 사용자가 방향감을 잃지 않게 하는 변화. 예를 들어 같은 사각형을 커졌다 작아지게 만드는 것.
- **Morph** — 한 형태가 부드럽게 다른 형태로 바뀐다. 예: Dynamic Island.
- **Shared element transition** — 썸네일이 카드로 확장되듯, 요소가 한 위치에서 다른 위치로 이동하며 변형된다.
- **Layout animation** — 요소의 크기나 위치가 바뀔 때, 딱 붙는 대신 새 자리로 애니메이션된다.
- **Accordion / Collapse** — 섹션이 콘텐츠를 보여주거나 숨기기 위해 높이를 부드럽게 확장·축소한다.
- **Direction-aware transition** — 콘텐츠가 앞으로 갈 때 한 방향으로, 뒤로 갈 때 반대 방향으로 슬라이드해서 내비게이션에 방향감을 준다.

### 스크롤 — 스크롤이나 뷰 간 이동에 연결된 모션
- **Scroll reveal** — 요소가 뷰포트에 들어오면서 페이드되거나 슬라이드되어 제자리를 잡는다.
- **Scroll-driven animation** — 진행 상태가 스크롤 위치에 직접 연결된 애니메이션.
- **Parallax** — 스크롤하는 동안 배경과 전경이 다른 속도로 움직여 깊이감을 만든다.
- **Page transition** — 한 페이지나 라우트에서 다른 곳으로 이동할 때 재생되는 애니메이션.
- **View transition** — 브라우저가 두 상태나 페이지 사이를 모핑하며 공유 요소를 연결한다.

### 피드백 & 상호작용 — 사용자의 행동에 반응하기
- **Hover effect** — 커서가 요소 위로 이동할 때의 시각적 변화.
- **Press / Tap feedback** — 요소가 클릭될 때의 미묘한 축소, 물리적으로 느껴지게 함.
- **Hold to confirm** — 사용자가 버튼을 누르고 있는 동안 채워지는 진행 효과.
- **Drag** — 요소를 잡아서 이동시키는 것, 놓을 때 관성이 붙는 경우가 많다.
- **Drag to reorder** — 리스트의 항목을 드래그해서 순서를 바꾸는 것, 다른 항목들은 자리를 만들어주기 위해 이동한다.
- **Swipe to dismiss** — 드로어나 토스트처럼, 요소를 화면 밖으로 드래그해서 닫는 것.
- **Rubber-banding** — 경계를 넘어 드래그할 때의 저항과 스냅백(iOS 오버스크롤 느낌).
- **Shake / Wiggle** — 오류나 거부된 입력을 알리는 빠른 좌우 흔들림.
- **Ripple** — 탭한 지점에서 원이 퍼져나가며 눌림을 확인시켜준다.

### Easing — 애니메이션 동안 속도가 변하는 방식
- **Easing** — 애니메이션이 빨라지거나 느려지는 비율.
- **Ease-out** — 빠르게 시작해서 느리게 끝난다. 대부분의 UI와 사용자에게 응답하는 모든 것의 기본값.
- **Ease-in** — 느리게 시작해서 빠르게 끝난다. 보통 피한다; 굼뜨게 느껴질 수 있다.
- **Ease-in-out** — 느림, 빠름, 느림. 이미 화면에 있는 요소가 A에서 B로 이동할 때 좋다.
- **Linear** — 일정한 속도. UI에는 피한다; 스피너나 마퀴에 아껴둔다.
- **Cubic-bezier** — 정밀한 제어를 위해 직접 정의하는 커스텀 easing 커브.
- **Asymmetric easing** — 가속과 감속이 다른 비율로 일어나는 커브. 대칭 커브보다 더 살아있게 느껴진다.

### 스프링 애니메이션 — 고정 지속시간 easing의 대안이 되는 물리 기반 모션
- **Spring** — 정해진 지속시간이 아니라 물리(장력, 질량, 감쇠)로 구동되는 모션.
- **Stiffness / Tension** — 스프링이 목표를 향해 얼마나 강하게 당기는지. 높을수록 경쾌하게 느껴진다.
- **Damping** — 스프링이 얼마나 빨리 안정되는지. 감쇠가 낮을수록 더 많은 바운스와 진동이 생긴다.
- **Mass** — 애니메이션되는 요소가 얼마나 무겁게 느껴지는지. 질량이 클수록 더 느리고 굼뜨게 움직인다.
- **Bounce** — 목표를 지나쳤다가 안정되는 스프링, 장난스러움을 더한다.
- **Perceptual duration** — 내부적으로는 미세하게 계속 안정되고 있어도, 스프링이 끝난 것처럼 느껴지는 시간.
- **Momentum** — 특히 드래그나 중단 이후에도 속도를 유지하는 모션.
- **Velocity** — 요소가 얼마나 빠르게, 어떤 방향으로 움직이는지. 중단되면 스프링이 이를 다음 애니메이션으로 이어받아, 튕긴 요소가 속도를 유지한다.
- **Interruptible animation** — 먼저 끝나기를 기다리지 않고 중간에 부드럽게 방향을 바꿀 수 있는 애니메이션.

### 루프 & 앰비언트 모션 — 스스로 실행되는 애니메이션
- **Marquee** — 텍스트나 콘텐츠가 루프로 계속 스크롤된다.
- **Loop** — 정해진 횟수만큼, 또는 무한히 반복되는 애니메이션.
- **Alternate (yoyo)** — 시작으로 되돌아가지 않고, 매 반복마다 앞으로 갔다가 반전되는 루프.
- **Orbit** — 요소가 다른 요소 주위를 연속적인 경로로 도는 것.
- **Pulse** — 시선을 끌기 위한 부드럽고 반복적인 scale 또는 opacity 변화.
- **Float** — 정적인 요소를 살아있고 가볍게 느끼게 만드는, 부드럽고 지속적인 상하 부유.
- **Idle animation** — 요소가 상호작용을 기다리며 가만히 있는 동안 재생되는 미묘한 모션.

### 다듬기 & 효과 — 좋은 것과 훌륭한 것을 가르는 작은 손길
- **Blur** — 요소를 부드럽게 하거나 미세한 결함을 가리는 데 쓰이는 blur 필터.
- **Clip-path** — 리빌, 마스크, before/after 슬라이더에 쓰이는, 요소를 특정 모양으로 잘라내는 것.
- **Mask** — 모양이나 그라디언트를 이용해 요소의 일부를 숨기거나 드러낸다 — clip-path와 비슷하지만 부드럽고 페이드 가능한 가장자리를 갖는다.
- **Before / after slider** — 겹쳐진 두 이미지를 비교하기 위해 드래그로 닦아내는 구분선.
- **Line drawing** — 보이지 않는 펜이 그리는 것처럼 스스로 그려지는 SVG 경로.
- **Text morph** — 값이 바뀔 때 글자 단위로 애니메이션되어 새 값에 시선을 끄는 텍스트.
- **Skeleton / Shimmer** — 콘텐츠가 로드되는 동안 보이는, 움직이는 광택이 있는 플레이스홀더.
- **Number ticker** — 숫자가 목표값까지 굴러가거나 카운트업된다.
- **Tabular numbers** — 숫자가 바뀔 때 흔들리지 않도록 고정 너비를 갖는 자릿수. 티커, 타이머, 카운터에 필수.
- **Typewriter** — 타이핑되는 것처럼 텍스트가 한 글자씩 나타난다.

### 성능 — 모션이 끊기지 않고 부드럽게 유지되는 요인
- **Frame rate (FPS)** — 초당 그려지는 프레임 수. 부드러운 모션의 기준선은 60fps; 최신 디스플레이에서는 120fps.
- **Jank** — 브라우저가 애니메이션 속도를 따라가지 못해 프레임을 떨어뜨릴 때 보이는 눈에 띄는 끊김.
- **Dropped frame** — 브라우저가 그리는 시한을 놓친 프레임, 모션에 작은 끊김을 만든다.
- **Compositing** — 레이아웃이나 페인트를 다시 하지 않고, GPU가 자체 레이어에서 요소를 이동하거나 페이드하게 하는 것.
- **will-change** — 요소가 곧 애니메이션될 것이라는 CSS 힌트로, 브라우저가 미리 자체 레이어로 승격시킬 수 있게 한다.
- **Layout thrashing** — width, height, top, left 같은 속성을 애니메이션해서 매 프레임 레이아웃을 재계산하게 만들어 jank를 일으키는 것.

### 알아야 할 원칙 — 언제, 어떻게 애니메이션할지 이끄는 개념들
- **Purposeful animation** — 모션은 단순한 장식이 아니라 기능을 수행해야 한다 — 방향 제시, 피드백 제공, 관계 표시.
- **Anticipation** — 어떤 움직임이 일어나기 전, 반대 방향으로 취하는 작은 예비 동작으로 다음에 일어날 일을 암시한다.
- **Follow-through** — 주된 모션이 멈춘 뒤에도 요소의 일부가 계속 움직이다가 살짝 더 안정되며, 무게감을 더한다.
- **Squash & stretch** — 무게, 속도, 유연성을 전달하기 위해 요소가 움직이며 형태가 변형되는 것.
- **Perceived performance** — 실제로는 아니어도, 올바른 애니메이션은 인터페이스를 더 빠르게 느껴지게 만든다.
- **Frequency of use** — 사용자가 애니메이션을 자주 볼수록, 더 짧고 미묘해야 한다.
- **Spatial consistency** — 요소가 상태 전반에 걸쳐 정체성과 위치를 유지하도록 애니메이션해서, 사용자가 사물이 어디로 갔는지 절대 놓치지 않게 한다.
- **Hardware acceleration** — transform과 opacity를 애니메이션하면 GPU가 모션을 부드럽게 유지할 수 있다.
- **Reduced motion** — 사용자의 prefers-reduced-motion 설정을 존중해서 모션을 줄이거나 제거하는 것.
